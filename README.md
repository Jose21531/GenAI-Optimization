# GenAI-Optimization

Proyecto del curso **Generative Artificial Intelligence (580694)** para transformar descripciones en lenguaje natural de problemas deterministas de programación lineal o programación lineal entera mixta en formulaciones matemáticas correctas, paramétricas y verificables. El sistema formula el modelo; no resuelve el problema de optimización.

El modelo utilizado actualmente es **Qwen/Qwen2.5-1.5B-Instruct**. La ejecución oficial se realiza en **Google Colab con GPU NVIDIA T4**.

## Ejecutar en Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Jose21531/GenAI-Optimization/blob/main/notebooks/Deliverable2.ipynb)

1. Abre `notebooks/Deliverable2.ipynb` con el botón anterior.
2. En Colab, selecciona **Entorno de ejecución > Cambiar tipo de entorno de ejecución > T4 GPU**.
3. Ejecuta las celdas en orden.
