# Deliverable 1 · Diagnóstico del caso oftalmológico

Esta entrega estudió la formulación matemática de la localización de dos centros oftalmológicos entre tres lugares candidatos, con cinco sectores de demanda. La formulación debe minimizar la distancia ponderada por población, abrir exactamente dos centros, asignar cada sector una vez y permitir asignaciones solo a centros abiertos.

- [Informe de Entrega 1](Grupo1_GenAI.pdf)
- [Notebook de Entrega 1](Deliverable_1.ipynb)

El diagnóstico mostró omisiones y contradicciones en la respuesta inicial del modelo. La [Entrega 2](../Deliverable%202/README.md) evalúa el ajuste QLoRA para mejorar la formulación, con un benchmark separado de 30 problemas.
