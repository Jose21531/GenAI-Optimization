# Prompts versionados

Cada agente tendrá un archivo `<agente>_vN.md`. Las variantes experimentales cargarán versiones o configuraciones explícitas; no se incrustará texto de prompts en Python. Una revisión crea un archivo nuevo y se documenta en `docs/decisiones.md`.

Los responsables B y C prepararán los prompts de sus agentes después de acordar `schemas.py` con A.
